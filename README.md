# To-Do-Lis
***Don't use it at now because there are too many bugs. I try to fix this***

This is a very simple TO DO list app. 
## Usage 
- add [A task is add by this command]
- remove [Remove a task from the task list]
- done [This command add a task fully]
- tasks [This command shows all task]
- incomplete [This shows the incompleted task]
- complete [This shows the completed task]
- exit [exit to the app]
- help [Show the commands]


## Run
```
node main.js
```
